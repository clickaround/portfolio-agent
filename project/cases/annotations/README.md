# Page annotations
A page annotation should answer **why**, not only where. Recommended structured fields: `page_role`, `project_claim`, `hero_asset`, `supporting_assets`, `hierarchy`, `reading_path`, `whitespace_strategy`, `typography`, `photo_vs_drawing_weight`, `story_prev`, `story_next`, `strengths`, `weaknesses`, `rights_scope`, `reviewer`, `confidence`.

Do not turn an anonymous website image into a factual claim about how a studio evaluated the project. Human labels are subjective, retain annotator disagreement. Text extraction/crops may require license clearance. Link-only source remains link-only.
