# Why portfolios must not look like generic AI reports

Fail examples: generic 3 equal cards per spread, identical image boxes across unrelated projects, excessive prose, unrelated decorative generative renders, unexplained repeated layouts, no narrative or visual protagonist, distorted screenshots/drawings, auto-caption hallucinations, style derived from a single screenshot without rights check.

Review whole book (not independent page beauty only): author identity, target audience, project selection & order, rhythm, deliberate blank space, hero vs supporting image variation, authentic visual proof, precise credit/role, pages that communicate one coherent idea. Request 3 **structurally** different variants, not 3 color palettes. Annotated rationale must connect layout choice to project evidence. Assess via independent expert blind review with failures captured as reusable structured traces.
