# ADR: Plugin-first before web SaaS

**Status:** PROPOSED (not accepted/implemented)

## Decision hypothesis
Why: exploit user-established Claude Code/Codex capabilities, reduce authentication/UI/orchestrator scope. Alternatives: stand-alone web app, server workflow. Test: P00 host loading + P04 backend smoke. Reverse: if users cannot install or portfolio workflow needs shared sessions, revisit.

## Required evidence
Reproduction reports, design benchmark deltas, measured cost, license audit, owner approval.

## Revisit criterion
Change as soon as bounded falsification experiment contradicts the hypothesis.
