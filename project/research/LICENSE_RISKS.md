# 상용 이용·저작권·보안 검토

**법률 자문이 아닌 기술적 위험 기록. 배포 전에 원문 약관과 제3자 자산까지 별도 검토한다.**

1. `HarnessRouter/harnessrouter` Community Edition은 공개 저장소에서 Apache-2.0으로 표시됨. **그 사실은** `HarnessRouter/starter-kit/kits/`에 그대로 적용되지 않음.
2. [HarnessRouter starter kit LICENSE](https://github.com/HarnessRouter/starter-kit/blob/main/kits/LICENSE.md)는 별도 계약: 개인 로컬 사용과 상용 제공/유료 고객 납품이 다름. 자체 호스팅 상용 사용은 별도 계약/요금 필요. **Slides Kit 코드를 본 제품에 복사하지 말고 먼저 라이선스 확인.**
3. [OpenPencil](https://github.com/open-pencil/open-pencil) README MIT, [GenOffice](https://github.com/genspark-ai/genoffice) README Apache-2.0으로 표시됨. 번들 폰트, 모델, PDF 라이브러리, 이미지 출처는 별도.
4. [Diagram Design](https://github.com/cathrynlavery/diagram-design) MIT 표기. SVG 예시에도 폰트/외부 자산 경로와 연결 요청 유무 확인.
5. [PyMuPDF](https://pymupdf.readthedocs.io/)는 AGPL/상용 양자택일 유의. 상용 SaaS 파일 파이프라인에 무심코 끼우지 말 것.
6. 포트폴리오 공개 웹페이지 ≠ 저장/재배포/학습 허가. 사용자 자료는 원칙적으로 작업용으로만 처리하고 훈련 재사용은 별도 동의.
7. 레퍼런스 수집은 출처 URL·저작자·이용 범위·허가 증거·만료·삭제 요구 대응을 기록. 불확실한 사례는 메타데이터/링크만 남기고 원본 미저장.
8. 테스트용 held-out 전문가 포트폴리오와 실제 고객 자료는 공개 ZIP/GitHub에 포함하지 않는다.
9. Claude/Codex API/프로 플랜의 사용 약관과 모델 호출 방식은 별개다. 외부 서비스 과금/클라이언트 제품 배포 권한을 가정하지 말 것.
