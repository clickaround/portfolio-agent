# 대화형 디자인 편집 연구와 적용 범위

확인일: 2026-11-09. 논문의 모델·데이터·평가를 재현하거나 결과를 이 프로젝트 성능으로 이전하지 않았다.

| 논문 | 확인한 핵심 | 이 프로젝트에 적용하는 방식과 차이 |
|---|---|---|
| [MiLDEdit](https://arxiv.org/abs/2601.04589) | 다중 레이어 문서에서 어떤 레이어를 수정할지 이해하고, 지시 수행·레이아웃 일관성·미관·텍스트 렌더를 함께 평가한다. | 편집 가능한 객체·선택 상태를 읽는 도구가 필요하다. 논문의 학습 모델·이미지 편집기는 이 구현에 포함하지 않는다. |
| [Seeing is Improving](https://arxiv.org/abs/2603.22187) | 렌더된 시각 결과를 다시 보고 레이아웃을 반복 개선하는 방법을 연구한다. | 단순 객체 좌표만으로 디자인 품질을 판단하지 않는다. 렌더된 페이지를 시각 모델에 전달하고 재검토하는 경로는 별도 구현·검증이 필요하다. |
| [MIRA](https://arxiv.org/abs/2511.21087) | 시각 관찰·추론·단일 편집을 반복하는 에이전트를 연구한다. | 요청을 작은 수정으로 나누고 매 단계 다시 읽는 방향을 채택한다. 논문의 이미지 생성 모델, 학습 및 평가 결과를 구현했다고 주장하지 않는다. |
| [Editable Visual Design](https://arxiv.org/abs/2609.04034) | 생성된 시각 요소와 편집 가능한 레이어·텍스트를 분리하고 렌더 피드백을 활용한다. | DesignCraft의 실제 편집 객체를 유지한다. 논문의 HTML/CSS 실행과 이미지 생성 파이프라인은 현재 구현하지 않는다. |

첫 구현: 사용자가 동의하면 DesignCraft가 반환한 현재 문서의 제한된 구조를 대화에 포함한다. 이 정보는 저장된 PDF 텍스트와 출처가 다르며, 사진이나 렌더 이미지를 모델이 본 것은 아니다. 이후 안정적인 revision과 객체별 수정, 실제 렌더 미리보기, 시각 입력 모델, 변경 후 검증·undo가 순서대로 필요하다. Claude 사용 한도 등으로 모델을 실행하지 못하면 이를 실패로 표시하며 합성 테스트를 실제 모델 성공으로 취급하지 않는다.
