# First-party portfolio editorial guidance (public sources)

- [Georgia Tech graduate portfolio guidelines](https://arch.gatech.edu/portfolio-guidelines-graduate-applications): 4–5 representative projects recommended, plans/sections/3D/analysis, editing of the presentation itself and clear individual contributions.
- [UIC graduate portfolio guide](https://arch.uic.edu/sites/arch.uic.edu/files/pdfs/Portfolio%20Guide_2.pdf): emphasis on original design thinking, authorship/role, controlled typography/columns/gutters, drawings prepared for vector quality.
- [Harvard GSD application FAQ](https://www.gsd.harvard.edu/offices-and-facilities/admissions-office/apply/navigating-application-faq/): project date/type/credits, image/line weights, file limits; no standard winning style.
- [AUT architecture portfolio guidelines](https://www.aut.ac.nz/study/study-options/architecture-and-built-environment/portfolio-guidelines-applying-to-study-architecture): work selection and design process.
- [University of Pennsylvania supplementary portfolio guidelines](https://admissions.upenn.edu/how-to-apply/preparing-your-application/supplementary-materials): AI disclosure can be required.
- [UMass architecture portfolio guidance](https://www.umass.edu/architecture/academics/undergraduate-studies/portfolio-content-and-presentation-guidelines): specific prohibitions on generative AI in some admissions contexts.
- [AHO Oslo design portfolio](https://www.aho.no/english/studies/admission/design-portfolio.html): page hierarchy, spacing, attribution and project division.

These are **institution-specific policies**, not universal architectural law or approval of using generative AI. Target program/employer rules override generic guidance.
