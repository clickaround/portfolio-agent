# Domain extension contract

Each domain pack contains `README.md`, `rubric.json`, a later `asset-ontology.json` and `page-archetypes.json`. The generic core knows only source asset metadata, project evidence, project/page sequence, style tokens, output format and editable scene. Domain rules are optional selectors—not hardcoded schemas. Unknown domains use `generic/` but trigger a reviewer warning; do not claim full specialist coverage.
