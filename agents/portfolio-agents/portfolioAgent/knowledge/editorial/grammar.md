# Editorial composition rules — starting hypotheses (NOT learned design laws)

The human 'art director' task is to decide: **which asset deserves attention, why now, and in what sequence?** The model must produce an argument (`BookPlan`) before coordinates (`Scene`).

## Page system
- `dominant_asset`: primary evidence, can be a plan/section, not necessarily a render.
- `supporting_assets`: explain main claim, not decorate empty regions.
- `reading_path`: designed eye sequence, must be clear at target page size.
- `density`: adapt to page role; avoid constant template rhythm.
- `negative_space`: reserve whitespace as intentional content.
- `type_roles`: title, contextual label, drawing legend, caption; consistent hierarchy.
- `contrast`, `grids`, `alignment`: precise, but don't force equal columns everywhere.
- `source_provenance`: every element linked to original item or authored note.

## Anti-report tests
- Flag every page using identical large headings + 3 symmetric cards + paragraphs without reason.
- Flag 'invented metrics', fake badges, gradients and decorative icons in professional drawing pages.
- Flag 3+ dense prose blocks on a page whose dominant information is visual.
- Flag key plan/section shrunk to thumbnail solely to fit supporting text.
- Flag identical page layout across a long project sequence unless justified.
- Flag automatically recreated CAD drawings as image-generation outputs.

The critic's finding is **proposal**, not a final rule; require expert pairwise review. There is no universal 'best' portfolio style. A portfolio for an experimental design studio may violate one of these heuristics on purpose.
