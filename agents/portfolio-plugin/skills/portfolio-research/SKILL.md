# Portfolio Research (research-only)

Use for finding/annotating real architecture, UX, branding or photography portfolios, or when a project lacks style references. Read `../../project/cases/README.md`, selected `../portfolioAgent/knowledge/domains/<domain>.md`, and `../../project/cases/case.schema.json`. Work from the FULL multi-page reference and purpose when possible, never a single attractive screenshot alone. Record links, rights ../../project/evidence/status, portfolio project/story sequence, page-by-page roles, lead visuals, typography, whitespace, and *why*. Avoid simple visual copying, mass scraping or model training. If rights are not granted, use source URL metadata only; do not copy images to public repo. Output actionable rationale for `portfolio-plan` plus gaps. This skill **does not create a finished PDF**.
