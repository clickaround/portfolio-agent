# Human blind review form (design critique)

Show paired renders at the SAME print/display scale. Blind reviewer to model/host/backend, randomize order. Questions:
1. Which portfolio tells the stronger **project story**? A / B / tie / cannot judge. Why?
2. Can you identify the project and its principal design argument quickly? A / B / tie.
3. Are the primary drawings readable and correctly prioritized? A / B / tie / invalid.
4. Which has more deliberate typography, composition, white space, and page-to-page rhythm? A / B / tie.
5. Does one look like a templated AI report/dashboard rather than a professional portfolio? Which and why?
6. Would you submit/show it without manual fixes? yes/no per output; name needed fixes.
7. Any factual/source/rights violations? Record blocker with screenshot.

Keep independent judgments and inter-rater disagreement. Include `reviewer_experience` but avoid leaking identity unnecessarily. Never claim blind evaluation conducted until forms actually returned. Separate preference metric from editability and document validity.
