# Scorers
- `scripts/check_layout.py` is a **tiny contract test**, not a full DOM/print/fact evaluator. It detects page-bound violations and bounding-box overlaps in synthetic Scene JSON.
- P03 will implement independent real scorers for input provenance, PDF zoom/diff, text overflow and localized edit mutations, and test deliberately invalid cases.
- Public GDB/SlidesGen/DECKBench score adapters are considered only after code/data license and repeatability audit, not by copying all packages into one environment.
