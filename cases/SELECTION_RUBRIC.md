# Choosing portfolio reference cases

Don't select only by social media popularity. Evaluate with at least two independent architectural/editorial reviewers where available. Score on separate 1–5 ordinal axes: 1) project argument readable at glance, 2) right asset is hero, 3) drawing/readability integrity, 4) purposeful negative space/hierarchy, 5) multi-page sequence/variation, 6) fit for intended audience, 7) ownership/source clarity. Unknown cannot become 5.

For each evaluated work, save a review rationale and disagreeing opinions. Collect **whole books with page sequence**, not isolated pretty screenshots. Distinguish published 'showcase', graduate applications, workplace resumes, and tender proposals. Domain-first: architecture initial, UX/branding/photography only as research counterexamples.
