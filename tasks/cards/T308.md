# T308 — 가변 출력 규격 무결성

## Goal
mm, bleed, binding, square, page/spread and invalid dimensions.

## Prerequisites
T301.

## Authorized paths
benchmarks/reports/format-contract.md; plus task-specific temporary fixtures; never modify source originals.

## Minimum steps
1. Read canonical docs and pinned source evidence.
2. Define concrete success and falsification examples before using tools.
3. Implement the smallest independent probe; record actual commands and outputs.
4. Confirm negative fixture fails and recovery or alternate behavior is logged.
5. Deliver `benchmarks/reports/format-contract.md` and write `evidence/P03/T308.md` with evidence levels.

## Pass gate
Reproducible command + output hash, exact exit status, actual results and remaining uncertainty. **Do not PASS if an external backend was not actually run.**

## Failure gate
Any unsupported claim, missing license review, inaccessible external files, bad geometry or absence of evidence must be FAIL/BLOCKED rather than invented success.
