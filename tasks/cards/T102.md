- **Goal:** 기존 링크 후보의 존재·페이지 전체성·제작자·공개 약관 점검
- **Scope / artifact:** `cases/catalog-audit.jsonl`
- **Expected effort band:** S (relative, not a schedule)

## Procedure (one bounded task)
1. Read `AGENTS.md`, `memory/NOW.md`, this card, and only relevant sources.
2. Write a falsifiable precondition/negative case; record current environment and existing files.

5. Ask independent reviewer to inspect the evidence and unexpected changes.
6. Update task record **only after evidence exists**; report BLOCKED with cause if external permission/data is missing.
