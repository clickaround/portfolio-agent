# Task DAG v0.2.0

`tasks/backlog.json` is the executable dependency source; `tasks/cards/Txxx.md` is the smallest task contract. `python scripts/task_status.py --ready` lists proof-backed unblocked work. `docs/TASK_RUNBOOK.md` is the single source for task transitions and parallel safety.

- Start with T000, followed by independent T001/T002 host discovery and T100/T200 read-only research as available.
- Real portfolio examples **are required for credible design quality research**, but a rights-approved portfolio is NOT required to run synthetic technical QA, external backend smoke and contract tests. Missing rights blocks only rights-dependent tasks and real-world quality claims.
- Alternative backend failures must be logged without falsely declaring success. HTML/PDF fallback remains open; an uninstalled optional backend must not freeze all work.
- P03 includes synthetic negative fixtures **before** genuine blinded evaluations. Keep final quality tests separate by creator/project.
- P06 product implementation is not included in the design ZIP; this is an executable engineering plan, not finished generator.
- P08 HarnessRouter is optional, subject to API/runner costs and separately licensed Starter Kit restriction.
