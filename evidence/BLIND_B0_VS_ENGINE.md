B0 = `claude -p` in an empty scratch dir with Read/Write/Edit/Bash(python); it did NOT see our repo, skills or engine (it did run with this machine's global Claude config/plugins). B0 template signs named: repeated header/footer pattern, keywords repeated, generic closing page.
Interpretation: the hypothesis "Portfolio Skill (engine) > general AI" is NOT supported on aesthetics for this case; the engine's value so far is gates, local-edit proof, provenance, export. Confounds: one project, one run per condition (LLM output varies), synthetic placeholder text/captions penalise the engine more (it prints the fixture text verbatim, B0 rewrote copy from project.md - allowed by prompt but a content-fidelity question), footer disabled in the engine candidate, single LLM critic with possible bias toward serif/editorial look.
Not measured: B1-B5, Codex host, repeated runs/variance, blinded human experts, local-edit capability of B0's PDF (it has none: one-shot PDF, no editable source).
