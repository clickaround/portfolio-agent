# Portfolio Agent — multi-domain, plugin-first editorial portfolio system

Project blueprint for a **professional portfolio art director**, not an AI-generated report. Supports cross-domain reference selection, content selection, coherent books/decks, image/text/vector editing, print & digital exports, independent benchmarks, versioned project state. Uses Claude Code / Codex as hosts; optional HarnessRouter later for unified orchestration. No runnable external backends are bundled.
