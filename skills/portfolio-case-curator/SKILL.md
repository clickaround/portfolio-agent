# Portfolio Case Curator

Research from public sources and user-provided materials. First check source rights and user permissions. Public URLs are metadata pointers, not reusable art/training material. Never automatically download/display/store full copyrighted works for model training. Record domain, audience/purpose, author, full project sequence, page roles, hero/supporting assets, omission rationale, typography, grid, pacing, distinctive design, anti-patterns, and source. Save only lawful analysis, annotations and explicitly permitted assets. Separate retrieval case set from heldout evaluators by creator/project. Mark unknown quality as unknown, not 'best'.
