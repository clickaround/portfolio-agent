# Supabase 데이터 계층 (구현 중)

`drafts/portfolio_conversation_foundation.sql`은 프로젝트·대화·메시지와 텍스트 part의 기반과 사용자 메시지 전용 트랜잭션 함수를 포함한다. 미완성 파일의 자동 배포를 막기 위해 migrations 폴더 밖에 둔다. assistant 저장, 로컬 프로젝트 이관, 에이전트 이력과 API/UI 연결은 아직 없다. 기존 앱은 이 스키마를 사용하지 않는다. 실행 가능한 최종 마이그레이션으로 취급하거나 배포하지 않는다.

`tests/portfolio_rls.sql`은 테스트 계정 두 개가 준비된 일회용 DB에서 소유자 읽기, 타 사용자 접근 거부, 사용자 위조 쓰기 거부, 작성자 불일치 거부 및 순차 메시지 재전송 멱등성을 검증한 뒤 롤백하는 SQL이다. 초안과 테스트를 한 트랜잭션으로 지정된 Supabase 프로젝트에서 실행하고 롤백한 실험은 성공했고, 이후 공개 테이블 목록이 비어 있음을 확인했다. 이 검증은 실제 API/JWT 통합, 동시성, 모든 CRUD, 성능, Storage, 에이전트 또는 마이그레이션 재실행 안전성을 증명하지 않는다.

다음 구현에는 사용자 메시지 함수의 동시성 검증, 신뢰 가능한 서버 전용 assistant 쓰기, 로컬 프로젝트 ID·소유권의 명시적 매핑, 실행 이력, API·UI 연결 및 전체 RLS 테스트가 필요하다. 사용자 프로젝트는 자동으로 이전하거나 삭제하지 않는다.
