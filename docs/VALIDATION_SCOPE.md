# What is tested and what is not

**Unit/static tests only:** package manifest readability, task DAG, evidence status policy, finite-geometry bounding boxes, explicit overlap exception, raw file hash and safe path, scoped JSON edits. No render engine, no installed host plugin, no vector preservation, no domain classification model, no case rights approval, no blind human design evaluation, no business payment validation.

The test data is entirely synthetic. A PASS here is proof of functioning **scaffold checks**, not proof of a design product.
