# ADR: Backend-neutral document and adapter

**Status:** PROPOSED (not accepted/implemented)

## Decision hypothesis
Why: neither OpenPencil nor GenOffice confirmed fidelity. Alternatives: native editor vs PPTX vs SVG/PDF compositing. Test: real vector PDF insertion, output zoom fidelity, local edit in both; select by evidence.

## Required evidence
Reproduction reports, design benchmark deltas, measured cost, license audit, owner approval.

## Revisit criterion
Change as soon as bounded falsification experiment contradicts the hypothesis.
