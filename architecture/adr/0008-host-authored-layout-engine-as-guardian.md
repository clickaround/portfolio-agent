# ADR-0008 - Let the host author layouts; the engine acts as guardian, exporter and editor (PROPOSED - first test NOT supportive)
Context: blind comparison (evidence/BLIND_B0_VS_ENGINE.md) favoured a general host's direct PDF over our rule-based layout (0.73 vs 0.35, n=1). GDB (arXiv 2604.04192) also reports weak precise spatial reasoning in frontier models, so host-authored geometry still needs deterministic checking; B0 passed most gates but has no editable source and fails our margin check.
Decision (proposed, needs more runs): stop investing in rule-based aesthetic layout. Accept host-authored page specs (scene JSON in mm following contracts/scene-document.schema.json, or HTML) and run them through: asset hash/provenance gates, geometry gates, bounded repair, DesignCraft/PPTX export, local-edit proof, independent critic. The rule-based solver stays as a fallback and as a repair aid (text fit, overlap resolve).
Falsification: with >= 3 projects x 3 repeated runs per condition, B4 (host-authored + gates + export) must beat B0 on blind expert preference OR on gate/edit outcomes at similar quality; if not, drop the claim.

## Update 2026-11-04 (B4 measured)
B4 (host-authored scenes + gates) scored 0.39 vs B0 0.76 vs engine 0.45 in one blind run (evidence/BLIND3_B0_B4_ENGINE.md). Gates passed first try, so guardian value is real but aesthetics lost. Hypothesis: the Scene Document vocabulary is too poor typographically (one family, regular/bold, one colour, no italic/alignment/tints). Next experiment BEFORE re-testing B4: extend the scene contract (per-element font role/style/colour/alignment/line-height, tint fills, hairlines) under a schema version bump, implement in backends/local (+DesignCraft styles), then rerun B4 x 3 projects x 3 runs. If still below B0, drop the claim and keep the engine as export/edit/provenance tooling only.

## Update 2026-11-04 (evening): B4 follow-ups
Four variants tested against B0 (evidence/BLIND3B..5): typography tokens helped (+~0.2), grid helper and visual self-review did not. Best B4 0.60-0.64 vs B0 0.74 (n=1, synthetic, one critic). The aesthetic claim of this ADR is NOT supported. Decision (as pre-registered above): the engine is positioned as gate + export + edit + provenance guardian, not as a better designer; do not market B4 as higher quality. Re-test only with real, rights-cleared projects and blinded human review.
