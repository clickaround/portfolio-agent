# ADR-0005: domain-independent document contracts + format-first output
Status: PROPOSED pending Technical Spikes, 2026-11-04.
Decision hypothesis: use domain packs for semantics, format specs for mm/px dimensions, shared source references for evidence, small typed role handoffs for optional parallel agents. Avoid writing a universal editor before baseline comparisons. Consequences: more adapter/contract work but less hardwired architecture-specific logic. Measure format parity and quality before acceptance.
