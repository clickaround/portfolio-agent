# ADR: Case library and domain knowledge are mandatory

**Status:** PROPOSED (not accepted/implemented)

## Decision hypothesis
Why: without curated real portfolios, model trends to report-style generic layouts. Alternatives: prompts only, mass crawl. Test: same inputs with/without case retrieval + domain pack; blind pairs. Raw images only with rights; no mass crawl initially.

## Required evidence
Reproduction reports, design benchmark deltas, measured cost, license audit, owner approval.

## Revisit criterion
Change as soon as bounded falsification experiment contradicts the hypothesis.
