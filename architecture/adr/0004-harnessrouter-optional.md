# ADR: HarnessRouter optional, post-MVP

**Status:** PROPOSED (not accepted/implemented)

## Decision hypothesis
Why: native host workflows suffice for pilot; UHP useful for multiple harness/model comparisons later. Risk: Docker/provider keys, license of Starter Kit separate. Test: P08 repeat task with UHP; evaluate overhead.

## Required evidence
Reproduction reports, design benchmark deltas, measured cost, license audit, owner approval.

## Revisit criterion
Change as soon as bounded falsification experiment contradicts the hypothesis.
